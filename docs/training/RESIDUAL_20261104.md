## 研究用本格学習の判定

研究用 seed 17 の TF-GridNet 35 epoch / SEMamba++ 100 epoch は、先行の研究設定の検証と今回の短い再開・評価・環境検証を合わせ、**条件付き GO**。公式学習との同一性を保証する判定ではない。SEMamba++ は 0.5 秒の短縮 epoch と 3 秒の研究設定を区別し、TF-GridNet は旧 5,000 更新 checkpoint を公式 chunk epoch の checkpoint とみなさない。PESQ 欠損の扱いは上記のとおり。長時間ジョブは資源・出力先を指定した明示承認後に開始する。今回、投入・開始はしていない。
